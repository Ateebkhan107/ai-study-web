# Offline build without changing the typefaces

Reviewed 2026-10-22 against installed Next.js 16.3 font/security guides. No font assets downloaded, packages installed, font imports changed or production styling changed.

Current imports require five families: Rajdhani (500/600/700), Space Grotesk (300–700), JetBrains Mono, Fraunces and Source Sans 3. All request latin and display swap; retain the existing five CSS variable names, applied class names, variable axes/ranges and fallback behavior. There are no font binaries under src/public to vendor from this checkout.

`next/font/google` downloads CSS/assets at build time, even though browser requests are self-hosted. A fully offline build therefore needs approved assets first. Recommended: acquire exact corresponding font versions from an official pinned google/fonts revision (or verified existing build artifact), record URL/revision/SHA-256 and each family's license/copyright, then commit approved local binaries and notices. Use `next/font/local` with matching variable names, weights/styles and font metrics. Do not assume every upstream release has identical metrics to the currently fetched Google CSS. Keep the corresponding CSS unicode ranges/subsets and variable axes under review; TTF is supported, WOFF2 is preferable when exact approved assets exist. Do not install a conversion tool without approval.

Acceptance: compare representative landing, dashboard, formula-book, test and mobile screenshots with approved baseline; inspect weight/axis and fallback metrics, line breaks, text widths and layout shift. Run a fresh-cache build with network denied and synthetic environment only. Then verify emitted assets are local and browser fonts produce no Google requests. A cached build alone is insufficient evidence of reproducibility.

Do not replace fonts with system fonts, mock font-loader responses, disable TLS checks, or allow production network credentials merely to obtain a green build. Production import changes remain a separate small change after approved asset acquisition and visual regression testing. The current isolated build fails on blocked Google Fonts requests; later compilation/rendering stages remain unverified.

Sources: [Next font reference](https://nextjs.org/docs/app/api-reference/components/font), [local font guide](https://nextjs.org/docs/app/getting-started/fonts), [official Google Fonts repository structure](https://github.com/google/fonts/blob/main/README.md?plain=1). Check each actual family's included license before redistribution.
