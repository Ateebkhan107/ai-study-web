# PrepZii Design System

PrepZii should feel like modern JEE/NEET preparation meeting a scientific notebook: focused, academic, warm, and polished without drifting into generic AI/SaaS styling.

## Visual Language

- Use cream paper in light mode and black/ink notebook surfaces in dark mode.
- Use PrepZii yellow/gold as a controlled accent for priority, selection, and progress.
- Prefer ink, slate, muted subject colors, simple borders, dividers, rows, tables, and whitespace.
- Use subtle ruled-paper, grid-paper, margin-line, measurement, answer-sheet, and formula-card references.
- Use custom SVG line-art for educational ideas: physics diagrams, circuits, graphs, molecules, vectors, optics, waves, and geometry.
- Use Font Awesome for common interface actions only: search, filters, timer, profile, settings, trophy, leaderboard, navigation.
- Use Web Awesome only for interaction behavior such as tooltips, dialogs, dropdowns, tabs, switches, drawers, and popovers.

## Avoid

- Purple/blue SaaS gradients, neon glow, glowing orbs, generic AI illustrations, sparkles as decoration, heavy glassmorphism, excessive pills, crowded bento grids, cards inside cards, and putting every content block in a card.
- Generic motivational copy. Prefer real PrepZii content, exam names, chapter names, scores, years, attempts, and clear study actions.

## Page Motifs

- Test: exam paper, timer, answer sheet, question navigation, marked-for-review states.
- PYQ: archive, paper records, year/session metadata, chapter filters, saved questions.
- Formula Cards: index cards, notebook pages, annotations, diagrams.
- Analytics: measurement, rulers, graph paper, tables, trend lines.
- Battle: versus sheet, score strip, round state.
- Community: threads, replies, conversation rows, moderation clarity.

## Migration Rule

Migrate one page at a time. Keep functionality and data flow unchanged, reuse shared primitives first, then adjust page-specific layout and motif.
