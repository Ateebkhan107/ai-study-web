The time for 200 oscillations of the pendulum is found to be 100 second using a clock of 1 s resolution. The percentage accuracy in the determination of 'g' using this pendulum is 'x'. The value of 'x' to the nearest integer is:-

1.   2$\%$
2.   3$\%$
3.   5$\%$
4.   4$\%$
