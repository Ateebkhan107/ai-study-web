1.   $f(x) < 0, \forall x \in \mathbb{R}$
2.   $f(x)$ can take any value in $\mathbb{R}$
3.   $f(x) = 0, \forall x \in \mathbb{R}$
4.   $f(x) > 0, \forall x \in \mathbb{R}$
