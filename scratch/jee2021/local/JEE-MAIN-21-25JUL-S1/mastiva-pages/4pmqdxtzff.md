1.   8(2 + 2$\sqrt{3}$ + $\sqrt{2}$)
2.   8($\sqrt{6}$ + $\sqrt{2}$ + 2)
3.   8($\sqrt{2}$ + 2 + $\sqrt{3}$)
4.   8($\sqrt{6}$ - $\sqrt{2}$ + 2)
