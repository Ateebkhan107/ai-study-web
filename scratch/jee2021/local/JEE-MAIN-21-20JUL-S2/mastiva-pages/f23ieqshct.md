1.   $(A)$ is false, but $(B)$ and $(C)$ are true
2.   $(A)$ and $(C)$ are true while $(B)$ is false
3.   $(A)$ is true while $(B)$ and $(C)$ are false
4.   $(A)$ and $(B)$ are false while $(C)$ is true
